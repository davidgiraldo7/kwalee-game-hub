Board

Floor / Void: click (or drag) to carve the board into any custom shape. Void cells are removed from play and render as empty in-game.
Blocks: tap an empty floor cell to add a block (using the chosen colour and target size). Normal blocks occupy one cell and expand in-game to fill their size as the widest rectangle that fits (filling horizontal space first, then wrapping). Tap an existing block to erase it. Enable Locked in place for a block that expands but cannot be dragged. Enable Arrow block to choose horizontal or vertical-only movement.
Pre-expanded: a block that begins at a fixed shape (w×h) already full and can never shrink; its size equals w×h.
Move limit: the maximum number of player moves and resizes allowed in-game.
Each block shows its target size (e.g. 6) — players double-tap to pop it out to fill that many cells. The level is solvable when every block's size can be packed (as some rectangle) into the floor at once.

Export / Import JSON

Exported JSON matches a single entry of the LEVELS array in index.html. Colours are palette names (e.g. "red") drawn from the shared PALETTE, so the object can be pasted straight into LEVELS and played immediately.

LEVELS.json file

Build the game's LEVELS.json without touching the script. Load file imports an existing LEVELS.json (its first level opens on the board); Push current appends the level on the board to the file; Download saves the whole file with two-space indentation for easy editing. The game fetches LEVELS.json on boot.
