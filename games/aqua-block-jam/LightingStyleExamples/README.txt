Soft 3D Template - Static Starter

Purpose:
- Minimal starting point for building toy-like 3D games from scratch.
- Keeps polished lighting, soft shadows, and a sensible camera composition.
- Includes static primitive examples to show the visual baseline.

Included files:
- Soft3DTemplate.html
- soft-3d-template-bridge.js
- scene-presets/soft-3d-template-preset.js
- three.min.js
- OrbitControls.js

How to use:
- Open Soft3DTemplate.html in a local server.
- Replace the sample primitives inside the preset with your game objects.
- Keep the camera + lighting setup as your baseline visual style.

Built-in debug:
- Press D to toggle the debug panel.
- Camera and lighting controls update the scene in real time.
- Save stores your current setup to localStorage.
- Load restores the saved setup.
- Reset returns to the default starter look.
