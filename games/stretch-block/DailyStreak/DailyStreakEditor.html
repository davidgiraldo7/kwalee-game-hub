Daily Streak Editor

Author the cycle reward id, gift day, and prize copy. Opens from live DailyStreak/js/daily-streak-data.js. Labels / descriptions are translations.js keys. Item grants pull from Items/js/items-data.js.

Reward Enum

Ids become DailyStreakRewardId.NAME. Use SCREAMING_SNAKE_CASE.

Cycle Reward

Gift sits on Reward day within a track of Cycle length days. Post-reward weeks roll forward without a chest.

Export / Import

Drop the downloaded file into DailyStreak/js/daily-streak-data.js. Browse… sets the sprite path to DailyStreak/Assets/<filename> — copy the image there if needed.
