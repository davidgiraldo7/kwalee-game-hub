Progress Rewards Editor

Author absolute unlock tiers and reward enum ids. Opens from live ProgressRewards/js/progress-rewards-data.js. Item grants pull from Items/js/items-data.js. Labels and descriptions are translations.js keys. Export replaces the data file.

Reward Enum

Ids become ProgressRewardId.NAME. Use SCREAMING_SNAKE_CASE.

Tiers

levels (0 = off). After the final tier, that same prize repeats on this interval.

Export / Import

Drop the downloaded file into ProgressRewards/js/progress-rewards-data.js. Use Browse… on a tier to pick an image — the path is set to ProgressRewards/Assets/<filename>. Copy the image into ProgressRewards/Assets/ if needed.
